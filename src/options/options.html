Peruser

Bridge

The bridge is the local companion that stores your patches as files and runs the coding agent. Start it with npx peruser-bridge.

Agent

My preferences profile

The agent reads this on every run, and "Tailor to my profile" in the panel applies it to the current page. Stored as profile.md in the bridge folder; edit it there if you like.

JavaScript patches

Off by default. JavaScript can do anything the page can. Peruser refuses scripts that read cookies or storage or send data elsewhere, shows you the code before saving, stores it as script.js, and rates such patches at least medium risk. Turning a patch off runs its cleanup; a reload undoes it completely.
